因此本轮观测不构成 CA 已激活的证据。邻区列表里同一 RAT/PCI/ARFCN

LTE + NR 各一个不报告同制式 CA。未激活 SCC 不计入激活载波数。

## 元数据与射频联合检查

`audit_ca_feasibility.py` 逐项关联候选新增的 81 个 NR 能力节点与
P54/P70 的双 region CA linkage 表。两个 P54 profile 都没有这些新增
组合的精确双 region 行；P70 覆盖其中 79 个节点。

**region 不等于 component carrier**。同一频段的连续 CA 可能复用一个
region，不能由缺少双 region 行断言所有 81 个节点均不可用。
尤其两个 n78+n78 节点在 P70 也没有精确双 region 行，仍须追踪消费者
如何选择单/多 region 路由。此次结果证实结构差异，未证明运行时失败点。

发现 P54 最后一个双 region 行（索引 103，LTE B41+B42）与按频段和
模 29 推导的哈希分桶不一致。该推导对 P70 1090/1090 行成立，
P54 103/104 行成立。尚未证明 P54 原生哈希查找同样采用该算法和边界，
因此没有修改该行或哈希表。

实际硬件前端问题保持待处理：P54 n41 使用的 LTE41 衍生路由覆盖
2535–2655 MHz，P70 n41 路由覆盖 2496–2690 MHz；相同编号不代表相同
射频单元。需要把 RF unit、FE/MRX、device model、校准与天线依赖一起
对应，不能复制 donor 原始指针或别机校准。
